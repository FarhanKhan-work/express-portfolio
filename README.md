# Farhan Khan - Express Portfolio (INFR 3120 Assignment 2)

**Live site:** https://farhan-portfolio-ogoh.onrender.com

My personal portfolio built with Node.js, Express and EJS.

## How I built it
- Generated the project with `npx express-generator --view=ejs`
- EJS views with one shared layout (express-ejs-layouts) and header/footer partials
- Bootstrap 5 (https://getbootstrap.com) and Font Awesome 6 (https://fontawesome.com)
- All routes are in `routes/index.js`
- CSS, JS and images are in separate folders inside `public`
- Deployed on Render

## Pages
- Home `/`
- About Me `/about`
- Projects `/projects`
- Contact Me `/contact`

## Run it locally
npm install
npm start
Then open http://localhost:3000
